Charts the size of a word

Datatype is a font. Type {l:20,45,60,55,80} and it becomes {l:20,45,60,55,80}. The chart sits in the sentence, takes its size and color, and needs no script to draw.

The numbers on this page are made-up examples.

In a sentence

Weekly signups climbed all spring before leveling off in June.

Support tickets pile up early in the week and are nearly gone by Sunday.

Three of four teams hit their target this quarter.

In a table

On a Cue slide

In Cue you would type the chart where you'd type a number. Cue wraps it in the Datatype font, and it scales with the slide's type.

Real numbers in, 0 to 100 out

Datatype only reads whole numbers from 0 to 100, with no spaces, and up to 20 of them. So each chart on this page holds its real values in data-values, and a few lines of script scale them and write the {…} text. The same function gives each chart a label, because a screen reader would otherwise read out the braces and numbers.

<span class="dt" data-dt="l" data-label="Weekly signups"
      data-values="1210,1380,1295,1620,1810"></span>

  
Sparklines are scaled from their own lowest to highest value, to show the shape. Bars start at zero so their lengths stay honest. A build step could do the same and ship plain text with no script.

Things to know

  
    
    
  • Ligatures have to be on, and letter-spacing must be 0, or the raw text shows.
    • 
    
  • Safari needs both axes in one font-variation-settings declaration.
    • 
    
  • No axes or labels. It's a shape next to a number, not a figure on its own.
    • 
    
  • Copying the text copies the braces, not a picture.
    • 
    
  • SIL Open Font License, so it can be bundled with Cue or the site. Google Fonts serves only part of the width axis, so self-host the full file.
